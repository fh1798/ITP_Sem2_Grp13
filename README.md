# ITP Projekt Webshop 

## Überblick

Dieses Repository enthält die vollständige Umsetzung eines Webshops für Parfümprodukte, erstellt im Rahmen der Lehrveranstaltung „IT-Projekt“ (ITP) an der FH Technikum Wien im Sommersemester 2025.


## Ziele

Ziel des Projekts ist es, ein vollständiges IT-Projekt im Team umzusetzen. Der Fokus liegt dabei auf der Anwendung von Projektmanagement- und Softwareentwicklungsprozessen, weniger auf der technischen Perfektion der Lösung.


## Ordnerstruktur

- **`application/`**  
  Enthält die initiale Projektbeschreibung und Aufgabenstellung.

- **`documentation/`**  
  Beinhaltet:
  - das [Deployment Manual](./documentation/DeploymentManual.md)
  - das [User Manual](./documentation/UserManual.md)
  - eine Linkliste zum öffentlichen GitHub-Repository und Projekt-Board

- **`presentation/`**  
  Abschlusspräsentation (Video)

- **`protocols/`**  
  Sprint-Review-Protokolle

- **`sourceCode/`**  
  Quellcode des Webshops (Frontend & Backend in PHP)
