# Benutzerhandbuch

Dieses Dokument beschreibt die Nutzung unseres Webshops aus Sicht von Endnutzern. Es richtet sich an alle Benutzer, die Produkte ansehen, kaufen oder sich mit anderen austauschen möchten.

## Voraussetzungen

Zum Aufrufen und Nutzen der Website wird ein internetfähiges Gerät mit installiertem Webbrowser benötigt.

**Hinweis:** Da die Website derzeit nicht online gehostet wird, muss sie lokal oder auf einem eigenen Server bereitgestellt werden. Informationen zur Einrichtung finden Sie im [Deployment Manual](DeploymentManual.md).

Alle weiteren Informationen dieses Dokuments setzen voraus, dass die Website bereits im Browser geöffnet wurde.

## Benutzerkonto

Grundsätzlich ist die Website ohne Anmeldung nutzbar.

Einige Funktionen, wie der Warenkorb, das Forum oder der Chat, stehen jedoch nur registrierten Benutzern zur Verfügung.

Sie können sich über den Menüpunkt **"Registrierung"** oben auf der Seite registrieren. Bereits registrierte Benutzer melden sich über **"Login"** an.

## Funktionen der Website

### Allgemeine Seiten
- **Startseite (Landing Page):** Übersichtliche Einführung mit hervorgehobenen Produkten.
- **Artikelübersicht:** Alle verfügbaren Produkte, auswählbar, um in die Detailansicht zu gelangen.
- **Top 5 Produkte:** Anzeige der meistgelikten Produkte.
- **Impressum:** Weitere Informationen über das Projektteam.
- **FAQ:** Die wichtigsten Informationen zur Website auf einen Blick.

### Produktdetails
- Produkte können angeklickt werden, um Details wie Beschreibung, Preis und Bild zu sehen.
- Über die Detailansicht lassen sich Produkte dem Warenkorb hinzufügen.
- Auch können Produkte geliked oder kommentiert werden.

### Warenkorb & Checkout
- Artikel im Warenkorb lassen sich in der Anzahl ändern oder entfernen.
- Im Checkout-Prozess wird eine Liefer- und Rechnungsadresse angegeben.
- Aktuell ist der einzige Zahlungsweg „Rechnung“ (diese wird per E-Mail versendet).

### Benutzerbereich (nach Login)
- **Nutzerdaten:** Einsicht in persönliche Informationen sowie Liste aller getätigten Bestellungen.
- **Nutzerbearbeitung:** Ändern der gespeicherten Mailadresse sowie des Passworts.
- **Forum:** Austausch mit anderen Benutzern.
- **Chatroom:** Direkter Austausch mit anderen eingeloggten Nutzern.
